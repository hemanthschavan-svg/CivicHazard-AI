# CivicHazard AI

AI-Powered Civic Issue Reporting and Management Platform.

## Project Team
SENTINELS

## Features
- Citizen registration and login
- AI-powered civic hazard image classification
- GPS-based complaint reporting
- Unique complaint tracking
- Department officer dashboards
- Completion evidence uploads
- Independent verification
- Admin dashboard
- Complaint resolution tracking

## Technology Stack
- Python 3.12
- Flask
- HTML, CSS, JavaScript
- SQLAlchemy
- SQLite
- Transformers and PyTorch
- CLIP image classification
- Pillow

## Installation
1. Install Python 3.12.
2. Create a virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Configure your `.env` file using `.env.example`.
5. Run `python run.py`.
